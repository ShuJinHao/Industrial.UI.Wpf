# 接入与迁移

## 1. 原界面提取范围

来源仓库：`ShuJinHao/HuaDing-PreCharge`。

读取基线：`a961c3b605d881ed48a56decd002317e3711b962`。

参考文件：`Views/Interface/DataDisplayView.xaml`、对应 ViewModel 与 code-behind。

| 原界面 | 本次提取 |
| --- | --- |
| `GlobalManager.TrayList`、固定 ViewModel | 外部 GroupsSource / DevicesSource / SelectedGroup 绑定 |
| 左侧 `lb_group` 托盘选择 | DeviceBoard 列表区域；可替换 GroupItemTemplate |
| `SelectedItem.Cells` 电芯集合 | 显式 DevicesSource；集合不必叫 Cells |
| 电池帽、圆角电池体 | DeviceCard 的 Battery 外观 |
| 固定负压、温度两个数据槽 | 任意数量 Measurements；可替换 MetricTemplate |
| 固定绿色卡片 | 按外部 DeviceStatus 切换颜色；状态始终有文字 |
| DetailedCommand | 调用方 DetailCommand，参数为当前原始对象 |
| 硬编码尺寸与配色 | 可配置宽度、可覆盖资源、可替换模板 |

这是对展示结构与视觉资源的提取/重组，不搬运原业务 ViewModel。原项目与现场程序未修改。

## 2. 使用可选展示模型

```csharp
var group = new EquipmentGroup
{
    Id = "CABINET-01", Title = "设备柜 01", Subtitle = "A 区",
    Status = DeviceStatus.Running
};
var device = new DeviceItem
{
    Id = "SENSOR-01", Title = "温湿度传感器", Status = DeviceStatus.Normal
};
device.Measurements.Add(new MeasurementItem
{
    Label = "温度", Value = "26.8", Unit = "℃", Status = DeviceStatus.Normal
});
device.Measurements.Add(new MeasurementItem
{
    Label = "湿度", Value = "45.2", Unit = "%RH"
});
group.Items.Add(device);
Groups.Add(group);
SelectedGroup = group; // 调用方实现属性通知；如不需要初选则保留 null。
```

上述类型位于 `Industrial.UI.Wpf.Models`。展示模型不携带 PLC 地址、数据库连接或固定工序约束。`Tag` 可存调用方上下文；修改 Tag 本身不产生属性通知，不用于实时显示。

`MeasurementItem.Value` 用字符串表示已经格式化的展示值：数字的小数位、单位换算、枚举文本由业务适配层处理。null、空白统一显示 `—`，真实 `"0"` 正常显示 0。状态由外部决定，控件不会从数值推断报警。

离线时可以保留最后读数并显式传 Offline，也可以清空 Value；数据新鲜度及更新时间请由外部数据项或自己的模板展示。

## 3. 保留自己的业务模型

设备对象只需要满足自己模板中的属性绑定，不要求继承 DeviceItem。例如你的对象拥有 `EquipmentName`、`Readings`：

```xml
<ui:DeviceBoard GroupsSource="{Binding AreaList}"
                SelectedGroup="{Binding SelectedArea}"
                DevicesSource="{Binding SelectedArea.Equipments}"
                DetailCommand="{Binding ShowDetailsCommand}">
    <ui:DeviceBoard.GroupItemTemplate>
        <DataTemplate>
            <StackPanel>
                <TextBlock Text="{Binding AreaName}" FontWeight="SemiBold"/>
                <TextBlock Text="{Binding Description}"/>
            </StackPanel>
        </DataTemplate>
    </ui:DeviceBoard.GroupItemTemplate>
    <ui:DeviceBoard.DeviceItemTemplate>
        <DataTemplate>
            <ui:DeviceCard Title="{Binding EquipmentName}"
                           MetricsSource="{Binding Readings}"
                           Status="{Binding DisplayStatus}"
                           Shape="Panel"
                           DetailCommand="{Binding DetailCommand, RelativeSource={RelativeSource AncestorType={x:Type ui:DeviceBoard}}}"
                           DetailCommandParameter="{Binding}"/>
        </DataTemplate>
    </ui:DeviceBoard.DeviceItemTemplate>
</ui:DeviceBoard>
```

自定义模板应自行转发详情命令；控件不会猜测调用方的属性名。上例的 Readings 元素若不是 MeasurementItem，再设置 `DeviceCard.MetricTemplate`，绑定自有 Label/Value/Unit 属性即可。自己模板中的 DisplayStatus 应为 DeviceStatus 或由自己的转换器转换。

## 4. 单独使用卡片或阵列

```xml
<ui:DeviceCard Title="设备 A" Status="Running" Shape="Panel"
               MetricsSource="{Binding Values}"
               DetailCommand="{Binding InspectCommand}"
               DetailCommandParameter="{Binding}" Width="180"/>

<ui:DeviceGrid ItemsSource="{Binding Devices}" SelectedItem="{Binding CurrentDevice}"
               CardWidth="160" CardShape="Battery"
               DetailCommand="{Binding InspectCommand}"/>
```

独立 DeviceGrid 的默认模板针对 DeviceItem。传其他类型时设置 ItemTemplate。列表/卡片选择保留 WPF ListBox 的键盘导航与选择语义；详情是独立命令。

## 5. 主题换肤

默认样式通过 `Themes/Generic.xaml` 自动加载。常见主题资源：

| 键 | 用途 |
| --- | --- |
| Industrial.Surface / Canvas | 面板与页面背景 |
| Industrial.Text / Muted / Line | 正文、辅助文字、边框 |
| Industrial.Accent / Selection | 选中边框、选中背景 |
| Industrial.Normal / NormalSoft | 正常状态文字、卡片背景 |
| Industrial.Running / RunningSoft | 运行 |
| Industrial.Waiting / WaitingSoft | 等待 |
| Industrial.Warning / WarningSoft | 预警 |
| Industrial.Alarm / AlarmSoft | 报警 |
| Industrial.Offline / OfflineSoft | 离线/未知 |

在应用资源覆盖同名画刷即可，例如：

```xml
<SolidColorBrush x:Key="Industrial.Accent" Color="#3567D6"/>
<SolidColorBrush x:Key="Industrial.Selection" Color="#EAF0FF"/>
```

绘制形状完全由 WPF Border/Grid/Ellipse 完成，没有图标字体、图片皮肤和第三方主题依赖。整个 ControlTemplate 可由宿主替换；控件是非 sealed 的 Control / ListBox，便于后续扩展。

## 6. 迁入原项目的建议步骤

1. 先在独立示例工程运行，确认默认视觉、数据项宽度和状态样式。
2. 给原工程增加类库引用；先在新页面使用，保留旧页面作为对照。
3. 在原业务 ViewModel 外加展示适配层，将托盘映射为 EquipmentGroup，将电芯映射为 DeviceItem。也可直接使用原对象并提供两个模板。
4. 把温度、负压和状态的更新投递到原 UI Dispatcher；不要把旧的定时器和 GlobalManager 搬入类库。
5. 将原 DetailedCommand 接到 DetailCommand；核对参数、权限、对象身份和窗口生命周期。
6. 检查空列表、断线、未知数据、预警、报警、长标题、大字体、高 DPI、实际对象数量及刷新频率后，再替换旧界面。

所有“正常/报警”的业务判定、权限、测点单位与阈值仍由原系统负责。默认示例中的 kPa 仅为演示，接入时必须使用真实测点单位，不能据此推断原现场数据含义。
